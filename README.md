# XILON JARVIS

Android-first, local AI assistant. No mandatory cloud inference.

## Integration policy
Upstream components must have reviewed licenses, pinned revisions, adapters and real tests before being marked integrated. No simulated success.

## Candidate upstreams
- https://github.com/ggml-org/llama.cpp — local LLM
- https://github.com/ggml-org/whisper.cpp — speech recognition
- https://github.com/k2-fsa/sherpa-onnx — offline speech
- https://github.com/OpenVoiceOS/OpenVoiceOS — skills architecture
- https://github.com/alexylem/jarvis — voice plugins

All candidates are pending source and license review; none is bundled yet.
